# Quant Lab research game

Educational stock-return simulation and historical replay. No brokerage or trade execution.

**Live site:** https://quant-lab-jaiden-731.korporatemonkee3.chatgpt.site/  
**Project log:** [docs/project-log.md](docs/project-log.md)
**Version checkpoints:** [docs/versions.md](docs/versions.md)

The website, JavaScript simulation model, Python reference model, Yahoo Finance adapter, build scripts, and tests live together in this repository. `web/` contains the game and the readable Python reference; `worker/` contains the server and price adapters; `scripts/` contains the build and verification tools. `web/data/history.json` is an archived teaching dataset. The generated `dist/` directory is omitted from version control.

Run `npm run build`, `npm test`, then `npm run dev`. The build embeds web assets into a Cloudflare Worker ES module at `dist/server/index.js`. Keep the Site project ID and current public audience unchanged.

## Data

Four bundled company histories (AAPL, MSFT, IBM, SBUX) and the archived index series come from https://github.com/plotly/datasets/blob/master/stockdata.csv, subset 2013–2016. Corporate-action adjustment methodology is not verified. New rounds with real history start price paths at the dated source close, while illustrative rounds without history use an index of 100. Older V1/V2 journal rounds retain their index-100 basis. Other company inputs are explicitly illustrative until CSV or provider data is supplied.

Yahoo Finance is now the default price adapter through its unofficial public chart endpoint, with no account, cookie, crumb or key. `/api/prices?symbol=AAPL&provider=yahoo` requests two years of completed daily bars by default; `days=504` or `days=1260` requests up to ten years for longer replay, while an optional `origin=YYYY-MM-DD` requests a bounded window around a selected replay date. Rows use adjusted closes when provided, exchange-local dates, USD currency validation, and exclude unfinished current-session daily bars. Vendor adjustments may be revised and can include dividend effects; they are not a point-in-time fundamental dataset.

Stock selection and the initial game view load daily prices automatically. Forward lab is the initial mode. A cancellable, deduplicating loader ensures late responses cannot replace a newer company selection. Successful requests are cached for up to 15 minutes. Errors never silently replace existing data; HTTP 429/401/403 produce explicit messages and cooldowns. There is no credential scraping, alternate-host rotation, or automatic retry. Yahoo's upstream availability must be checked from the actual hosting environment; a no-key adapter being configured is not proof it can retrieve data.

`/api/news?symbol=AAPL&provider=yahoo` attempts recent Yahoo Finance headlines through an unofficial public endpoint. It may return 429 or deny server access, as observed during development; the Research page links directly to Yahoo Finance when it cannot load. This endpoint is not a historical news archive and is withheld in replay. Server-only `ALPHA_VANTAGE_API_KEY` retains optional Alpha Vantage prices (`provider=alpha`) and news. `ALPHA_VANTAGE_ADJUSTED=true` selects adjusted closes when the plan permits. No secret is needed for Yahoo. Browser price checks occur every 15 minutes only while Forward lab is open and unlocked. There is no unattended background schedule or chat access.

CSV imports and forecast journals use local browser storage. The Forecast journal has Export journal JSON and Import journal JSON controls: export a backup before clearing browser data or switching devices, then import it to restore saved rounds. Import validates records, merges by record ID, and recomputes evaluation scores. Reloads retain records in the same browser; there is no account sync. Evaluated forecasts are ranked by CRPS improvement against each run's unchanged baseline, with per-stock summaries and one-factor score sensitivity checks. Repeated runs on one outcome are not independent evidence, and cross-stock ranks mix different prediction tasks. Forecasts are frozen before replay reveal; this is an educational browser simulation, not a tamper-proof competition. Generic event descriptions are not reconstructed dated news. Historical vendor revisions, adjustment basis, survivorship, and source consistency require independent review for production research.

## Model

Exact physical-measure GBM with antithetic common random numbers; annualization 252. Up to 252 pre-origin log returns calibrate volatility. Drift is 25% raw sample estimate + 75% illustrative 5% prior, capped at -20%/+25%. Slider coefficients are illustrative and averaged within groups before summing. Sensitivity caps are explicit in Math and Python. A separate user-controlled one-time jump scenario is implemented; its probability and move size are not estimated. Stochastic volatility is not implemented.

Black–Scholes sandbox on the Stock Calculator uses the dated starting share price, scenario volatility (not option-chain IV), and user-entered European pricing inputs under Q. Forecast scoring uses empirical CRPS and interval coverage; one round cannot establish calibration. Allocation scoring assumes zero cash yield and a 10bps round-trip cost, without taxes/dividends/execution.

V2 adds a direct proposed-investment input and one-month, three-month, or one-year horizons. For example, a $1 million proposed Apple purchase projects a distribution of dollar profit/loss from the current slider-weighted simulation. A practice budget and allocation percentage remain editable. The app shows expected and median net P/L, an 80% simulated P/L range, modeled 5th-percentile P/L, loss frequency, and approximate whole shares using a dated close when available. A model-preferred sizing band maximizes simulated CRRA utility under a user-entered 5th-percentile loss limit, then repeats with lower drift to expose estimation sensitivity. The calculation uses a single stock plus zero-yield cash and is conditional on the current forecast model, not a validated personal investment recommendation. Prior V1 journal records still import and display.

The later V2 teaching update moves assumptions before the price scenarios and money decision, adds keyboard-accessible hover explanations, and starts new real-data price paths at the dated share close. The middle 80% chart band and ending interval are 10th–90th percentile summaries; they are not standard-deviation confidence intervals or real-world guarantees. A separate 1–30 year holding illustration analytically compounds the current constant GBM parameters and is excluded from forecast locking and scoring. Price paths and replay dollar outcomes use source closes, while adjusted returns may have informed calibration; projected dividends, taxes, and changing parameters are not modeled.

The Python file is a reproducible standard-library reference for the original GBM calculations; newer jump and portfolio code is in JavaScript. It is generated from `scripts/quant_model.template.py` with the same company/factor catalog. Tests verify JavaScript/Python parity, GBM moments, CRPS, pricing identities, data validation, unconfigured Alpha behavior, Yahoo parsing/session completeness, cache reuse, and explicit upstream errors.

## Portfolio and page flow (November 2026)

The site now opens on an introduction, followed by tabbed tutorials for historical, forward, and portfolio play, then a short explanation of the Brownian model and sliders. In the Game, assumptions sit beside the graph on wide screens; event descriptions use tooltips, and longer technical sections are collapsed. The Stock Calculator holds position sizing, an inflation-adjusted long-term illustration, and the hypothetical options sandbox. Research combines company information, a filing guide, market context, and best-effort recent Yahoo headlines.

Portfolio mode accepts two to five distinct tickers, weights totaling at most 100%, zero-yield residual cash, a budget, and six horizons (21 to 1,260 sessions). It aligns up to 252 shared daily source returns (Yahoo-adjusted when provided), estimates correlations with 20% shrinkage toward zero, and simulates 600 correlated GBM buy-and-hold paths. A separate independent-shock aggregate is shown for comparison. A shared one-time event shock can affect every stock, while current game sliders can modify each company's marginal drift and volatility. Portfolio settings and single-stock scenario slots are browser-local. Multi-year forecasts hold estimated parameters fixed and are especially sensitive to model error; future inflation is a user assumption, not a Yahoo prediction. No rebalancing, dividends, taxes, or transaction costs are modeled in portfolio mode.

### Guided game flow and usability pass (November 24, 2026)

The Start page now has an interactive index-100 demonstration using the same JavaScript parameter and GBM code as the game. Its four-step guide explains dated price inputs, illustrative slider coefficients, Brownian shocks, and replay scoring. Historical and Future buttons open fresh rounds in the named mode, including when a different round was previously locked. A compact live-effect card beside the sliders shows current median, loss frequency, annual drift, annual volatility, and the latest factor's marginal parameter contribution.

The journal defaults to share-price rounds, with explicit controls for older index-100 rounds or all rounds. Its CRPS skill labels distinguish beating, matching, and underperforming the unchanged baseline. Individual records can be removed with an immediate Undo. Backup import accepts horizons up to 1,260 sessions. Portfolio loading withholds archived results until current Yahoo requests finish, then labels an archive fallback if needed. Portfolio inputs update the result while edited, its scenario cases use responsive cards, and each holding's calibrated parameters and source date are visible. The Stock Calculator option strike accepts cents, and the portfolio budget no longer has a step offset.

## Replay and S&P 500 update (November 25, 2026)

Historical replay now has a top-level New replay control. All factor groups open initially and remain collapsible. A results dialog awards a game win when the predicted median is closer to the actual ending value than the unchanged baseline median **and** the actual value falls inside the forecast's middle 80% interval. It shows the full error, interval, CRPS, allocation, and S&P 500 comparison; closing it leaves a compact result card that can reopen the scorecard. This is a game rule for a single historical round, not evidence of repeatable forecasting skill.

The Yahoo-backed `/api/benchmark` endpoint fetches the S&P 500 price index (`^GSPC`). After historical reveal, its realized path is rebased to the stock's origin share price and drawn in blue; the original index return is shown separately. In portfolio mode, a blue S&P 500 line is a **modeled forward GBM median** calibrated from current index history and scaled to the same starting budget. It is not a realized future path, an investable fund, or a total-return comparison. If data is unavailable or dates do not match, the chart explains why the line is withheld.

For horizons above 126 sessions, slider contributions to annual drift receive a bounded logarithmic multiplier based on the chosen session count, pre-origin stock volatility, and fixed company profile. Short horizons retain their original coefficients. Volatility still compounds over time through GBM's square-root-of-time diffusion; the horizon multiplier affects the **assumed drift sensitivity**, not the Brownian definition. The annual scenario drift is capped at −60%/+70%. These multipliers are illustrative and unvalidated; longer forecasts are especially sensitive to parameter error. The Python reference and Math page implement the same rule.
